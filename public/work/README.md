Assets de cada proyecto, organizados por slug:

  public/work/<slug>/cover.jpg     portada de la tarjeta y la ficha (~1200 px de ancho)
  public/work/<slug>/preview.mp4   clip mudo de 3-5 s en loop para el hover (~300 KB)
  public/work/<slug>/01.jpg        galería, para proyectos de fotografía
  public/work/<slug>/02.jpg

Las rutas deben coincidir con lo que declares en data/projects.ts.
Mientras no existan, se muestra el placeholder con el isotipo.
